# Google AI 套餐手册：AI Plus、AI Pro、AI Ultra（5x / 20x）

>
> **来源与限制：** 数据来自 [Google AI 方案页](https://one.google.com/about/google-ai-plans/)。我们读取到的是**日文版页面**，已按原文整理；页面**没有显示各档价格**，也没有写明价格是否因国家而异，只说明了可用范围因国家而异。所以本文**不写任何价格数字**，请以你所在地区的官方页面为准。

## 30 秒结论

- 个人订阅现在是三个系列：**Google AI Plus、Google AI Pro、Google AI Ultra**。
- **Ultra 现在分 5x 和 20x 两个档位**（相对 Pro 的用量倍数），早期"Ultra 只有一档"的说法已经过时。
- 订阅和 **Gemini API 是分开计费**的，订阅不等于 API 额度，见 [Gemini 订阅与 API 的区别](./gemini-subscription-vs-api.md)。
- 价格、存储、包含的功能因国家和地区而异，下单前以官方页面为准。

| Gemini Notebook | 扩展功能与模型 | 扩展使用 | 最高等级使用 |
| Gmail / Docs 等 | Google 应用内置 AI（如 Gmail 校对） | 含 Gmail、Docs、Sheets 支持；AI 收件箱摘要仅限美国 | 与 Pro 相同 |
| 开发者相关 | — | AI Studio、Antigravity、Jules 更高限额；每月 $10 Google Cloud 额度 | 更高限额；每月 $40 Google Cloud 额度（顶档表格为 $100） |

几点说明：

- "约 2 倍、约 4 倍"是页面对"相对非 Google AI 方案"的描述，不是绝对数字；
- 表里的功能和名称（如 Gemini 3.1 Pro、Flow 积分）会随版本调整；
- 官方页面对可用国家数的写法不完全一致（正文写 150 个以上，脚注写 140 个以上），说明**能不能买、买到什么因地区而异**。

## 名称是怎么变的

| 阶段 | 常见叫法 | 对应现在的 |
| --- | --- | --- |
| 早期 | Gemini Advanced、Google One AI Premium | 大致对应 Google AI Pro |
| 现行 | Google AI Plus | 入门档 |
| 现行 | Google AI Pro | 主力档 |
| 现行 | Google AI Ultra（5x / 20x） | 旗舰档，分两个倍数 |

老教程里的"Gemini Advanced"可以按 Pro 档理解，但具体权益以官方当前页面为准；"Ultra"现在要先问清是 5x 还是 20x。

## 选档自查

| 你的使用方式 | 更可能合适 |
| --- | --- |
| 日常问答、轻度研究，想要更多用量和存储 | Plus |
| Google 办公全家桶用得多，需要 Gmail / Docs 里的 AI、更多存储和 AI Studio 限额 | Pro |
| 高频视频与图像生成、大量 Flow 积分、旗舰功能刚需 | Ultra（再在 5x 与 20x 之间选） |

判断时看**你是否真的用得到某项独有权益**，而不是看档位高低。官网文章的讨论：[Gemini 会员：AI Plus、Pro、Ultra 怎么选](https://muyugpt.com/blog/gemini-recharge-plus-pro-ultra)、[Gemini 三档差异速查表](https://muyugpt.com/blog/gemini-plus-pro-ultra-table)。

## 怎么核对自己的地区能买到什么

1. 打开 [Google AI 方案页](https://one.google.com/about/google-ai-plans/)，选择你所在的地区版本，看当前显示的档位和价格；
2. 注意"仅美国""仅英文"这类限定（如 Gemini Agent、AI 收件箱摘要）；
3. 到你的 Google 账号的订阅管理里确认当前方案；
4. 订阅后以账号里实际出现的功能为准，个别功能会灰度发布。

## 常见问题

### Google AI Pro 和 Gemini Advanced 是一回事吗？
Gemini Advanced 是早期的付费方案叫法，现在大致对应 Google AI Pro；具体权益以官方当前页面为准。

### Ultra 到底有几档？
按官方方案页，Ultra 现在分 5x 和 20x 两档，存储分别为 20 TB 和 30 TB。

### 订阅里的 Google Cloud 额度，可以当作 Gemini API 额度用吗？
方案页只写了每月的 Google Cloud 额度金额，没有说明能用在哪些服务、能否抵 Gemini API 的费用，本文不作推断，见 [Gemini 订阅与 API 的区别](./gemini-subscription-vs-api.md)。

### 为什么我看到的功能和表里不一样？
功能会随地区、版本和灰度发布变化；官方页面对可用国家的数字写法也不完全一致。
