## 十一、Gemini 网页会员和 Google API 有什么区别？

**Gemini 的网页 / App 付费方案和 Google 的开发者 API 是两套不同产品与计费体系。**

- 开通网页会员**不等于**获得等额 API 额度；
- 需要程序调用接口的开发者，对应的是 API，而不是网页会员；
- 若你只是想在网页 / App 里用更强的 Gemini，一般对应付费方案而非 API。

买之前先想清楚你要的是「网页会员」还是「API 额度」。
